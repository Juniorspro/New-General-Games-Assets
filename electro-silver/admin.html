Una IA en la nube (opcional)

El botón mágico ya funciona sin esto: lo redacta la propia página, al instante y sin internet. Si querés que además reescriba de cero, con más vuelo, se le puede enchufar la IA de Google. Es gratis pero hay que sacar una clave.

  1. Entrá a aistudio.google.com/apikey con tu cuenta de Google.
  2. Tocá Create API key y copiala.
  3. Pegala acá abajo. No pide tarjeta.
Un cuidado, porque esta clave sí queda a la vista. Al revés de la de Supabase, ésta se puede usar desde cualquier lado. Cuando la web esté publicada, entrá a la clave en Google Cloud y en Application restrictions elegí Websites, agregando tu dominio. Así sólo funciona desde tu página. Mientras tanto, el plan gratis pone un tope diario, así que lo peor que puede pasar es que alguien te lo gaste.

Cuatro pasos, una sola vez

Ahora las publicaciones se guardan en esta computadora nomás. Para que las vea cualquiera que entre a la web, hay que darle un lugar en internet donde guardarlas. Usamos Supabase: es gratis, no pide tarjeta y alcanza de sobra.

  • 1
    Crear la cuenta y el proyecto En la página de Supabase. Te abro yo la pantalla exacta.
  • 2
    Pegar dos datos Copiás un bloque y lo pegás acá: yo saco lo que sirve.
  • 3
    Preparar la base Un botón copia el texto, otro te abre dónde pegarlo. Después verifico que haya quedado.
  • 4
    Tu usuario Lo creo yo con el mail y la contraseña que elijas.

1 · Creá la cuenta y el proyecto

Te abro la pantalla de proyecto nuevo. Si todavía no tenés cuenta, ahí mismo te la crea con el mail o con GitHub.

  1. Poné un nombre cualquiera, por ejemplo electro-silver.
  2. La contraseña de la base guardala, aunque acá no se usa.
  3. Elegí la región South America (São Paulo), que es la más cerca.
  4. Dale a Create new project y esperá el minuto que tarda.
Abrir Supabase

2 · Pegá los datos del proyecto

En Supabase andá a Project Settings → API. Seleccioná todo lo que veas ahí y pegalo en el cuadro. No hace falta que separes nada: yo saco la dirección y la clave que corresponde.

Prefiero pegarlos por separado

3 · Preparar la base

Esto crea la tabla de publicaciones, el depósito de fotos y los permisos: que cualquiera pueda ver y sólo vos puedas publicar. Es copiar, pegar y correr.

2 · Abrir dónde pegarlo

Pegalo en el cuadro grande, apretá Run (o Ctrl+Enter) y volvé acá.

Ver el texto 
-- Se puede correr las veces que quieras: no pisa nada.
-- Un mismo proyecto sirve para varios locales: los separa la columna "negocio".
create table if not exists publicaciones (
  id           uuid primary key default gen_random_uuid(),
  creado       timestamptz not null default now(),
  titulo       text not null,
  detalle      text,
  precio       numeric,
  precio_antes numeric,
  cuotas       int  not null default 0,
  rubro        text,
  whatsapp     text,
  imagen_url   text,
  visible      boolean not null default true
);

-- por si la tabla ya existía de antes
alter table publicaciones add column if not exists negocio text not null default 'electro-silver';
create index if not exists publicaciones_negocio_idx on publicaciones (negocio, creado desc);

alter table publicaciones enable row level security;

drop policy if exists "lectura publica" on publicaciones;
create policy "lectura publica" on publicaciones
  for select using (true);

drop policy if exists "escribe el dueno" on publicaciones;
create policy "escribe el dueno" on publicaciones
  for all to authenticated using (true) with check (true);

insert into storage.buckets (id, name, public)
values ('publicaciones', 'publicaciones', true)
on conflict (id) do nothing;

drop policy if exists "fotos lectura publica" on storage.objects;
create policy "fotos lectura publica" on storage.objects
  for select using (bucket_id = 'publicaciones');

drop policy if exists "fotos escribe el dueno" on storage.objects;
create policy "fotos escribe el dueno" on storage.objects
  for insert to authenticated with check (bucket_id = 'publicaciones');

drop policy if exists "fotos borra el dueno" on storage.objects;
create policy "fotos borra el dueno" on storage.objects
  for delete to authenticated using (bucket_id = 'publicaciones');
